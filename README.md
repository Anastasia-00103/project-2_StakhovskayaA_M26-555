## Управление таблицами

На данный момент реализовано создание, удаление и просмотр таблиц.

### Команды
- `create_table <имя_таблицы> <столбец1:тип> ...` — создать таблицу (поддерживаются типы `int`, `str`, `bool`).
- `list_tables` — показать список всех таблиц.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `help` — справочная информация.
- `exit` — выход из программы.

```text
>>> database

## Обработка ошибок и подтверждение действий

В проект добавлены декораторы для повышения надежности и удобства работы:

- **Обработка ошибок**: Все операции с базой данных обернуты в декоратор `handle_db_errors`. Он перехватывает исключения (например, отсутствие файла, неверные типы данных, обращение к несуществующей таблице) и выводит понятные сообщения, не прерывая работу программы.
- **Подтверждение опасных действий**: При выполнении команд `drop_table` и `delete` программа запрашивает подтверждение `[y/n]`. Это предотвращает случайное удаление данных.
- **Замер времени**: Операции `insert` и `select` замеряют время выполнения и выводят его в консоль (например, `Функция insert выполнилась за 0.001 секунд.`).
- **Кэширование**: Результаты одинаковых запросов `select` кэшируются в рамках одной сессии с помощью замыкания (`create_cacher`). Повторный запрос с теми же параметрами выполняется мгновенно, так как данные берутся из кэша.
