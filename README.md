# Primitive DB

Консольное приложение, имитирующее работу с базой данных. Поддерживает создание и удаление таблиц, CRUD-операции, обработку ошибок, кэширование и подтверждение опасных действий.

## Установка

1. Убедитесь, что у вас установлен [uv](https://docs.astral.sh/uv/).
2. Клонируйте репозиторий и перейдите в папку проекта.
3. Установите зависимости:
   ```bash
   uv sync

## Запуск

Запустите приложение командой:
uv run database

## Управление таблицами
На данный момент реализовано создание, удаление и просмотр таблиц.

## Команды
create_table <имя_таблицы> <столбец1:тип> — создать таблицу (поддерживаются типы int, str, bool).

list_tables — показать список всех таблиц.

drop_table <имя_таблицы> — удалить таблицу.

help — справочная информация.

exit — выход из программы.

## Пример использования
>>> database
***База данных***

>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.

## CRUD-операции с данными
База данных поддерживает создание, чтение, обновление и удаление записей.

## Команды
insert into <имя_таблицы> values (<значение1>, <значение2>, ...) — создать запись. Строковые значения должны быть в кавычках, логические — true/false.

select from <имя_таблицы> — прочитать все записи.

select from <имя_таблицы> where <столбец> = <значение> — прочитать записи по условию.

update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение> — обновить запись.

delete from <имя_таблицы> where <столбец> = <значение> — удалить запись.

info <имя_таблицы> — вывести информацию о таблице.

## Пример использования
>>> insert into users values ("Sergei", 28, true)
Запись с ID=1 добавлена в таблицу "users".

>>> select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>> delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи из таблицы"? [y/n]: y
Запись удалена из таблицы "users".

## Обработка ошибок и подтверждение действий
В проект добавлены декораторы для повышения надежности и удобства работы:

Обработка ошибок: Все операции с базой данных обернуты в декоратор handle_db_errors. Он перехватывает исключения (отсутствие файла, неверные типы, несуществующие таблицы) и выводит понятные сообщения.

Подтверждение опасных действий: При выполнении команд drop_table и delete программа запрашивает подтверждение [y/n]. Это предотвращает случайное удаление данных.

Замер времени: Операции insert и select замеряют время выполнения и выводят его в консоль.

Кэширование: Результаты одинаковых запросов select кэшируются в рамках одной сессии с помощью замыкания (create_cacher). Повторный запрос с теми же параметрами выполняется мгновенно.

## Пример работы подтверждения

>>> delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи из таблицы"? [y/n]: n
Операция отменена.
